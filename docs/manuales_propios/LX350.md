# Manual propio: Epson LX-350 (matriz de punto)

Comportamiento verificado en una Epson LX-350 real. Impresora **no fiscal** (notas de entrega y diario de notas).
Volver al [resumen del proyecto](../project.md).

## Conexión

- Linux: USB con driver `usblp`, dispositivo `/dev/usb/lp0` (`root:lp 660`). Requiere un permiso temporal (ACL) o
  pertenecer al grupo `lp`.
- Envío directo de los bytes ESC/P: `cat archivo.txt > /dev/usb/lp0`. El modo archivo del spooler (`txt`) genera
  exactamente esos bytes y funciona en cualquier sistema operativo (commit `1e5ff10`).
- Windows: el modo de impresión directa usa `win32print`; solo ese modo exige `win32`.

## Juego de caracteres (CP850)

| Método | Resultado |
|---|---|
| `ESC t 2` + ASCII (spooler anterior) | Todo carácter no ASCII sale como `?` |
| `ESC t 2` + CP850 | `ESC t 2` es la tabla de usuario: la impresora sigue en PC437 y `Á Í Ó Ú` salen como símbolos gráficos |
| **`ESC ( t 03 00 01 03 00` + `ESC t 1` + CP850** | **Correcto**: ñ Ñ á é í ó ú ü Á É Í Ó Ú ¡ ¿ |
| `ESC ( t` PC437 + `ESC t 1` + CP437 | Minúsculas correctas; `Á Í Ó Ú` no existen en PC437 y salen como `?` |

`ESC ( t 03 00 01 03 00` asigna PC850 a la tabla 1 y `ESC t 1` la selecciona. Los caracteres ñ, á, é, í, ó, ú, ü, ¡ y
¿ tienen el mismo código en CP437 y CP850; solo las mayúsculas acentuadas distinguen ambas tablas.

## Longitud de página

- `ESC C 0` **requiere** el byte `n` (pulgadas). Sin él, la impresora toma el siguiente byte (el `ESC` del comando
  siguiente, 27) como longitud: página de 27" y el comando siguiente se imprime como texto.
- Hoja carta: `ESC C 0 11`. El `FF` final avanza exactamente a la siguiente hoja (verificado).
- Media carta: `ESC C 33` (33 líneas a 1/6", es decir 5,5"). No verificado en papel.

## Inicio de documento del spooler

`ESC @`, luego `ESC ( t 03 00 01 03 00` + `ESC t 1`, luego `ESC C 0 11`, luego `ESC M` (12 CPI), contenido y `FF`
(commit `18299ca`).

## Contenido del documento

- Encabezado con el número del contador local (no la clave de idempotencia de Odoo) y la línea `REF:` con el nombre
  del documento (commit `3a147c2`).
- Totales calculados con el modelo: línea de descuento o recargo bajo el ítem (`Descuento 10.00%`, `Recargo 5.00%`),
  línea `DESCUENTOS:` solo si hay ajustes, y línea `AJUSTES`. No imprime IGTF.
- El contador se reserva, se imprime y se confirma bajo un candado, sin saltos ni duplicados. Si no se puede
  persistir el contador después de imprimir, se responde éxito y se registra un error crítico.
- El contador emulado se guarda en SQLite (tabla `counters` de `data/print_jobs.db`, fila `matrix`), no en el template JSON; ver `templates/templates.md`.
- Los títulos de columna se alinean como sus valores (commit `a39e68c`).
